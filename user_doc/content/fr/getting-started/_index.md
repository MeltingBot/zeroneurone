# Prise en main

Cette section vous guide à travers les premiers pas avec ZeroNeurone.

## Tutoriel guidé

Le plus simple pour découvrir l'application est le **tutoriel guidé intégré** : depuis la page d'accueil, cliquez sur « Tutoriel guidé » dans le bandeau de bienvenue, ou sur l'icône en forme de chapeau de diplômé dans le pied de page. Des bulles vous guident pas à pas — création d'un dossier d'entraînement, éléments, relation, tags, propriétés, événements, géolocalisation et découverte des vues Carte, Chronologie et Matrice. Chaque étape se valide quand vous faites réellement l'action ; vous pouvez passer une étape ou quitter à tout moment, et le dossier d'entraînement peut être supprimé à la fin.
